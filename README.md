## Curling League

This is a basic application to keep track of a curling leagues.
Leagues can be added and edited and information about each league
can be edited. Leagues can also be saved or loaded. 
Curling teams can be added to the league and members can be
added to the team or edited. Teams can also be imported or 
exported within the application.

### Execution 

The following are the steps to execute for windows.

1. Open a terminal.
2. Navigate to the directory in which the project is located. 
3. Install PyQt6 using command: pip install PyQt6
4. Execute application using command: python -m CurlingLeague.gui.league_main_window
